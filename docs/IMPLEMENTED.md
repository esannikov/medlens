# Склад оновлення07.09.2026

## Уточнення після перевірки користувачем

Останнє рішення: прибрати порівняння й постійні пояснювальні елементи.
Основна лінза тепер має стале поле, панелі відкриваються поверх нього.
Reader слідує за геометричним фокусом і показує тільки поточний запис.
Додаткові зв’язки, технічні відомості, масштаб і таблиця доступні через «Ще».
Легенди, компас, контекст «Відкрито / У лінзі» та постійний часовий ряд прибрані.
Старі адреси dual/lab повертають основну лінзу. Це рішення замінює відповідні
пункти початкового плану. [Перевірка](QUIET_VERIFICATION.md).

| № плану | Реалізація | Статус |
|---|---|---|
| 1 | Оригінал/канонічний запис одиниць тільки для відомої однакової шкали; позначення можливих повторів/відсутньої одиниці | Готово; джерела не виправляються автоматично |
| 2 | Точний облік підписів і повний перелік прихованих результатів | Готово |
| 3 | Обов’язковий центральний підпис, компактні варіанти та пам’ять розміщення | Готово для перевірених розмірів; довгі деталі можуть лишатися у списку |
| 4 | Один поточний фокус для лінзи й reader | Виправлено; синхронізацію перевірено під час drag |
| 5 | Таблиця поточного відбору | Порівняння A/B прибрано за рішенням користувача |
| 6 | Стале поле, накладені панелі даних і часу | Виправлено; геометрія не змінюється при відкритті панелей |
| 7 | Масштаб тексту, контрастні статуси, клавіатура й області натискання | Готово; не повна сертифікація доступності |
| 8 | Дослідження зберігають типізовану форму на периферії | Готово; назви/деталі розкриваються у фокусі |
| 9 | М’яке оптичне поле та ієрархія товщини зв’язків | Готово |
| 10 | Сталі координати при відборі, категорії в «Ще» | Дубльований компас прибрано |
| 11 | Деталізація тексту залежить від наближення, повний текст у reader | Готово |
| 12 | Розділені підстави дат, counts, фільтр і позначка issued в усіх нових режимах | Готово; не реконструкція історичної обізнаності |
| 13 | Список точних кандидатів, перевірка сумісності, інтерактивні точки | Код готовий; поточний пакет не дає достатніх підтверджених методів для фізіологічних серій |
| 14 | Додаткові точні структурні ребра на вимогу | Готово |
| 15 | Шлях до джерела й точний уривок | Готово; тільки public-safe текст |
| 16 | Форк із двома незалежними інтерактивними лінзами | Прибрано після перевірки користувачем |
| 17 | Форк групування за матеріалом/датою/типом і пошуку згадок | Експеримент; підтверджена анатомічна карта/модель тіла потребує відсутніх структурованих прив’язок |
| 18 | Статуси твердження, перевірки, сумісності й якості конкретних полів | Готово; без вигаданого процента впевненості |
| 19 | Локальні ревізійні закладки, відновлення та JSON маршруту | Готово; без зовнішнього зберігання чи прирівнювання відкриття до лікарського підтвердження |
| 20 | Прозорий пошук із типом/розділом/періодом/підставою дати | Готово як структуровані умови; не природномовний діагностичний агент; гіпотез у пакеті немає |

Лабораторію порівняння прибрано. Контрольний build зафіксовано до змін;
він залишається історичним артефактом поза основною навігацією.

Наукове дослідження з лікарями, новий експорт клінічних даних, виправлення
джерельного дубля та клінічне прийняття не виконувались і не підміняються UI QA.
