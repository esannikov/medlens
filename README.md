# MedLens

Експериментальна інтерактивна карта пацієнта з HematoBoard: рухома 2D-лінза, реєстр об’єктів, клінічні дати й точні структуровані джерела.

## Перегляд

[Відкрити MedLens](https://esannikov.github.io/medlens/).

Перетягніть гілку до центра: підписи й вузли збільшуються, відкриваючи вміст.
Натисніть підпис або «Дані», щоб прочитати поточний запис. Відкрита панель
слідує за фокусом лінзи; вона не зберігає інший, раніше відкритий аналіз.
Для показника спочатку видно назву, значення, одиницю, референс, дату,
матеріал і посилання на точне джерело.
Навігаційний шлях угорі — кольорові чіпи через «/» у палітрі лінзи;
насичений чіп позначає поточний вузол. Натискання повертає до обраного предка.

Підписи тепер розкриваються за активною гілкою. У дослідженні легких
ланцюгів автоматично видно тільки його матеріали, результати та шлях
до лабораторії/досьє; ЛДГ, глюкоза й інші дослідження лишаються приглушеними
знаками. Наведення тимчасово розкриває один сторонній запис, не перемикаючи
гілку. Під час drag нова читана ціль стабілізується за 150ms; клік і Enter
діють відразу. [Перевірка нової логіки](docs/REVEAL_VERIFICATION.md).

Поле й діаметр лінзи не змінюються при відкритті даних, часу, пошуку чи
переліку результатів. Панелі відкриваються поверх поля. Діаметр залежить
тільки від вікна та ручного масштабу. На вузькому екрані дані відкриваються
нижньою панеллю з власною прокруткою.

Чіпи мають окрему смугу над SVG і не перекривають компас. Вузол можна
захопити й одним рухом втягнути з периферії до центра: він тримається під
курсором. Перетягування за підпис зберігає відступ між ним і вузлом.
У панелі дослідження одразу видно описи й показники всіх його матеріалів.
«Звірити з джерелом» згорнуте під результатами; після розкриття назви
фрагментів пояснюють їхній зміст, сторінка є лише адресою.

Довгі зв’язки мають спільне для всього графа радіальне стискання. Під час
руху вузли та всі точки їхніх ліній пересуваються тим самим плавним
перетворенням. Зона читання всередині половини радіуса не стискається;
на маленькій лінзі додаткове стискання вимкнене. Розділи, дослідження,
матеріали та результати використовують одне правило, без винятків за назвами.
Попередня геометрія доступна за `?spacing=original`, нова — за `?spacing=compact`
(типово). Це окремі варіанти однієї сторінки, без повернення панелі порівняння.
[Механіка й перевірка стискання](docs/SPACING_VERIFICATION.md).

«Час» відбирає записи до обраної дати. Клінічна дата має пріоритет; якщо її
немає, використовується явна дата видачі дослідження з позначкою «видано».
Реєстрація й замовлення не підміняють видачу. Це відбір поточної ревізії,
не реконструкція знань у минулому. Patient Graph не змінюється.

Нерухоме внутрішнє кільце з м’якою світлотінню показує зону збільшення.
Вільні підписи змінюють розмір із наближенням до центра. Довгі описи мають
навігаційну назву зі стрілкою: натискання відкриває повний незмінений текст.
Це не автоматичний клінічний підсумок. «Усі результати» відкриває повний
перелік активної гілки, включно із записами без видимого підпису.

Кольоровий акцент і збалансована товщина зв’язків показують навігаційний
фокус, не клінічну важливість чи достовірність. Короткий блік реагує на
перетягування; системне зменшення руху його вимикає. Легенди, дубльований
компас, службові смуги й порівняння прибрано за рішенням користувача
07.09.2026. Старі адреси `?lens=dual` та `?lens=lab` відкривають основну лінзу.
Незмінний історичний build збережений у `control/`.

Наступне оновлення додало компас на зовнішньому кільці. Кольорові мітки
слідують за проєкцією кластерів під час руху лінзи; назви можна натиснути
для переходу. Це навігаційний обід, без повернення бічної легенди.
Розділ поточного фокусу на компасі не повторюється; після повернення до
огляду досьє знову видно всі напрями.
Підписи активної гілки розкриваються раніше. Наведіть на периферійний вузол,
щоб побачити його назву й значення без зміни фокуса. У щільній гілці всі
назви не показуються одночасно: доступні наведення, наближення й повний список.
[Перевірка компаса та розкриття вузлів](docs/COMPASS_VERIFICATION.md).

[Наукова основа лінзи](docs/LENS_FOUNDATIONS.md): focus+context,
гіперболічне дерево, диск Пуанкаре й семантичне масштабування.
Підписи, значення й дати використовують локальну Iosevka. За недоступності
шрифту вимірювання й показ разом переходять на системний моноширинний шрифт.
Довгі тексти панелі читання лишаються у звичайному шрифті інтерфейсу.
[Версія й ліцензія шрифту](public/fonts/iosevka/README.md).

## Дані

Знеособлений CASE024 має дозвіл на зовнішню публікацію. Це фіксована read-only проєкція схваленої ревізії Patient Graph, не нове джерело клінічної істини. Вона містить 185 об’єктів, 148 результатів і 306 структурних зв’язків. Оригінальні PDF, зображення, приватні файли, локальні шляхи й сесійні ключі не публікуються. Адреса джерела відкриває лише знеособлений структурований текст.

Базовий публічний пакет: [HematoBoard CASE024](https://esannikov.github.io/hematoboard/?case=case024). Хеші та склад цієї статичної проєкції: [publication.json](public/data/publication.json). Дати, значення, одиниці, невизначеність і статуси перевірки збережено; технічна перевірка інтерфейсу не означає клінічної валідації або лікарського прийняття. Демонстрація не призначена для ухвалення клінічних рішень.

Застосунок не має входу, завантаження документів, аналітики відвідувань чи запису змін. Дані статичного сайту загальнодоступні; `noindex` не є захистом доступу.

## Локальна розробка

Node.js 24; `npm ci`, `npm test`, `npm run dev`. Для перевірки саме статичної збірки: `npm run build`, потім `npm run preview`. Відкриття HTML через `file://` не підтримується.

React + TypeScript + SVG; власна реалізація гіперболічного фокуса. Three.js та попередні 3D-прототипи не входять до MedLens. Зміна даних потребує нового схваленого джерельного експорту; не редагуйте клінічні значення вручну.

Офлайн-експортер `scripts/export-publication.mjs` приймає явні шляхи до Graph, CaseScope і схваленого public package та перевіряє точні SHA-256 вхідних файлів до читання клінічних полів. Ці приватні входи не потрібні для запуску або збірки MedLens і не зберігаються в репозиторії.

GitHub Actions запускає тести й збірку перед публікацією `dist` на GitHub Pages. Відносні адреси підтримують розміщення в `/medlens/` без сервера застосунку.

## Додаткові інструменти

У «Ще» залишені таблиця, відбір за розділом, масштаб тексту, унормований
запис одиниць, структурні зв’язки, технічні відомості й локальні «Місця».
Унормування змінює тільки позначення відомих одиниць однакової шкали,
без перерахунку чисел. Пошук має додаткові умови типу, періоду й підстави дати.
Явне відкриття знайденого запису поза поточним відбором повертає все досьє,
щоб у фокусі й панелі з’явився саме цей запис, а не інший найближчий вузол.
Клавіші ←/→ ведуть до батька/дочірнього запису, ↑/↓ — між сусідами,
Enter відкриває читання. Escape закриває допоміжні панелі.

Технічні відомості показують джерельні статуси, можливі повтори та однойменні
показники лише за запитом. Числова серія потребує підтвердженої сумісності
методу, матеріалу, одиниць і клінічних дат; між вимірюваннями немає інтерполяції.
Клінічний текст і пошукові фрази не записуються в закладки або URL.

[Окремий експеримент перегрупування](https://esannikov.github.io/medlens/?lens=regroup)
залишається доступним за прямою адресою. Текстові анатомічні згадки в ньому
не є підтвердженою локалізацією. Гіпотези в цьому наборі відсутні.

[Перевірка спрощеного інтерфейсу](docs/QUIET_VERIFICATION.md).
